## 작업 지침

- 설계 계약을 바꾸면 대응 계획과 실제 구현에 미치는 영향을 함께 확인한다. 문서 간
  연결과 단계 구분을 유지하고, 계획을 수정했다는 이유로 구현 완료를 주장하지 않는다.
- 한국어 본문, 날짜가 포함된 파일명, 코드 블록과 체크리스트의 맥락을 보존한다.
- 버전, 명령과 현재 동작은 루트 설정·소스·테스트와 대조한다. 문서의 과거 실행 예시는
  현재 작업에서 자동으로 실행할 지시가 아니다.
- 변경 후 자식·형제 문서 링크를 확인한다. 검증 명령을 수정하면 루트 `README.md`와
  문서 회귀 테스트의 명령 문자열과 순서도 확인한다.
- 스펙과 구현이 다르면 해당 단계의 룰링부터 읽는다. 구현과 맞추기 위해 과거 설계나
  당시의 결정을 소급해서 다시 쓰지 않는다. 문서 검사는 [상위 안내](../AGENTS.md)를 따른다.
